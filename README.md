## The entry

> Calling in sick — my back went out celebrating that I finally had a day off, so now I need a day off from my day off.

One line, one sentence — the back injury is real enough to half-believe, but the cause is pure celebration: the day off itself hurt the back, so the cure is another day off. The twist lands on the last words.
